# Airbnb-Inspired Travel Accommodation Platform

About :-

This is a beginner full-stack project inspired by Airbnb.
Users can view and add travel accommodation listings.


Tech Used :-

* Node.js
* Express.js
* MongoDB
* Mongoose
* EJS



Features :-

* User signup and login
* Add new listings
* View listings
* Basic CRUD operations

Note :-

This is a learning project and still under development.
